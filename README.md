# C++ Bubble Sort CLI

A simple command-line application written in C++ that demonstrates sorting using the Bubble Sort algorithm.

## 📌 Features
- User input for dynamic integer data
- Input validation and error handling
- Bubble Sort implementation using `std::vector`
- Clean and readable output (before & after sorting)

## 🧠 Concepts Covered
- Time complexity: O(n²)
- Nested loops and iteration control
- Swapping using `std::swap`
- Input handling and stream validation
- Basic memory-safe container usage (`std::vector`)

## 🛠️ Tech Stack
- Language: C++
- Standard Library: `<vector>`, `<algorithm>`, `<limits>`, `<iostream>`

## ▶️ How to Run

```bash
g++ main.cpp -o app
./app
